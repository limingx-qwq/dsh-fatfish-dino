🐳 你好，我是大肥鱼

dsh-fatfish-dino · 一个不干正事但很好玩的 DSH 插件

① 悬浮球 · 点击即玩

右下角圆形悬浮球，点一下展开跑酷。空格 / ↑ / 点击跳跃，↓ 下蹲。可拖动换位置，最高分自动存在本机，破纪录会显示表情包。

② 思考强度 · GPT 式拖动条

下方输入框里的「思考深度」已被替换成胶囊拖动条：蓝紫渐变、燕尾斜切、白色圆点、档位名 + 模型副标题、⟳ 重置。拖动时显示吐槽文案。

③ 设置 → 外观 · 全局 UI 编辑器

点左侧「🎨 外观」打开 DSH 自带设置面板，插件会把「大肥鱼 · 全局外观」卡片注入到外观页里（不是悬浮球上的按钮）。背景类型支持跟随主题 / 纯色 / 6 组渐变 / 上传图片 / 上传或远程视频，另有毛玻璃、面板不透明度、压暗、圆角、辉光、应用范围与自定义 CSS。

素材与考据：百度贴吧《大肥鱼好可爱》 —— 本帖指向的「蓝色大肥鱼 / 鲸鱼娘 DeepSeek」二创梗（帖子回复为「dd」「今天没心思发吧，新模型太区了」，故角色素材按该表情包风格重新绘制）； B 站 BV1C5YZ69EdX 前 8 秒 —— 每 0.5 秒截帧共 16 帧，据此还原 GPT-6 / Codex 的「强度」拖动条。
提示：打开游戏后按 空格 开跑；点击悬浮球收起。右侧的 ⟳ 可把思考强度重置为「深度」。
